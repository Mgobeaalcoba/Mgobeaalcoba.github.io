Tus suscripciones de IA, ruteadas con datos.

ia-router manda cada tarea al modelo que mejor rinde en ese tipo de trabajo (Claude, Codex o Gemini) según métricas objetivas de Arena y Artificial Analysis, y no según la corazonada del día. Corre sobre los CLIs oficiales y tus propias suscripciones.

Instalación en una línea

Probalo en tu terminal

Homebrew$ brew install Mgobeaalcoba/tap/ia-router
pip$ pipx install ia-router

Python 3.9+ · Apache-2.0 · sin dependencias · código en GitHub

El problema

Pagás tres suscripciones. ¿A cuál le mandás cada tarea?

Elegís a ojo

Cada semana sale un modelo que es «el mejor». Sin un criterio común, decidís por costumbre.

Una cuota se agota y las otras sobran

Usás siempre el mismo modelo hasta el rate limit, mientras los otros dos quedan sin tocar.

Los rankings se mueven, tu configuración no

Lo que era cierto hace un mes puede no serlo hoy, y nadie te avisa qué cambió.

Cómo funciona

Un puntaje por modelo y por tipo de tarea, con datos publicados.

  1. 01

    Clasifica la tarea

    Código, debugging, escritura, análisis, matemática, contexto largo, imágenes… por reglas, sin gastar cuota.

  2. 02

    Puntúa cada modelo

    Precisión (Elo de Arena por categoría, con margen de error), velocidad (tokens por segundo) y costo (precio por millón de tokens), relativos a tus modelos.

  3. 03

    Ejecuta en tu CLI oficial

    Si hay rate limit o falta de login, prueba el siguiente. Cada respuesta muestra el modelo exacto y los tokens que gastó.

Todo es explicable: cada número tiene su fuente a la vista, y al actualizar las métricas ves qué cambió en el ruteo.

Casos de uso

Para quien usa varias IA todos los días.

Desarrollo diario con varias suscripciones

El código va al modelo más preciso según Arena y los benchmarks de coding; las tareas rápidas, al más veloz. Dejás de decidir por costumbre.

Cuidar la cuota

Para tareas repetitivas priorizás costo. El router reparte para que no se agote siempre el mismo modelo mientras los otros sobran.

Analizar archivos

Arrastrás código, imágenes o PDF a la terminal. El texto se anexa como contexto; imágenes y PDF van solo a los modelos que pueden abrirlos.

Documentos largos

Para contexto largo mira métricas específicas (razonamiento sobre contexto largo y consultas largas de Arena), no el promedio general.

Conectar tus apps (Gmail, Calendar…)

Registrás servidores MCP una vez y cualquier modelo los usa: resumir los mails del día, agendar un bloque en el calendario, consultar tu CRM.

Scripts y pipes

cat error.log | ia-router ask "¿qué falla?" --json: entrada por pipe y una salida JSON con el modelo, los tokens y el costo estimado, lista para shell, cron o CI.

Comparar dos modelos

ask --compare corre la misma tarea en dos modelos y muestra ambas respuestas con tiempo y costo. Siempre explícito, porque gasta cuota en cada uno.

Medir tu cuota

ia-router usage muestra tokens y costo estimado por modelo y qué tan cerca estás del límite que ya alcanzaste. No inventa límites: los aprende de tu propio historial.

Retomar conversaciones

ia-router --continue retoma la última conversación. Se guardan solo en tu máquina y podés apagarlo o borrarlas.

Delegar desde Claude Code

Se registra como servidor MCP: Claude Code puede pedirle al router que mande una subtarea al modelo que mejor encaja.

Equipos que evalúan modelos

Un criterio objetivo, reproducible y con fuentes citadas para decidir qué modelo usar, en lugar de opiniones.

Vos ponés el criterio

¿En código priorizás precisión, velocidad o costo?

Cinco preguntas de opción múltiple, una por tipo de tarea. Con tus respuestas el ruteo se rearma al instante, sin configurar nada a mano. Si no querés responder, rigen valores por defecto razonables.

  • Velocidad y costo se ofrecen solo cuando hay datos para todos tus modelos: nunca se mezclan escalas.
  • Las diferencias dentro del margen de error no premian a nadie.
Nuevo en 0.4 · Conectores

Que cualquier modelo use tus otras apps.

Registrás servidores MCP una sola vez (Gmail, Calendar, Drive, Slack, GitHub, tu CRM…) y el router se los da a claude, codex y agy a través de un único proxy, y cada tarea recibe solo los conectores que necesita. Un solo lugar para permisos, auditoría y credenciales, con el modelo que sea.

  • El router nunca toca tokens OAuth: cada servidor MCP hace su propio login. Las claves pueden ser referencias ${NOMBRE} a tu entorno.
  • Pueden leer y escribir: ocultá herramientas con listas allow/deny o apagalos con /connectors off.
  • Cada llamada queda en un log local, sin argumentos ni resultados.
  1. 1 · Registrá un servidor
    $ ia-router connectors add files -- npx -y @modelcontextprotocol/server-filesystem ~/Documents

    Usá el servidor MCP de la app que quieras; su documentación explica cómo iniciar sesión.

  2. 2 · Probalo sin gastar cuota
    $ ia-router connectors test
  3. 3 · Usalo desde el chat
    $ ia-router

    Con conectores registrados, cada tarea los usa; /connectors off los apaga. Para agy, una vez: ia-router connectors install agy.

Sin sorpresas

Pensado para no sacarte el control.

Tus CLIs oficiales, tu login

No toca tokens OAuth: cada CLI usa su propia sesión y su propia suscripción.

Sin «permitir todo»

Nunca activa flags que desactiven los permisos de los CLIs.

Instalar

Mac, Linux y Windows. Elegí tu sistema.

Disponible para macOS, Linux y Windows (con WSL 2). Requiere Python 3.9 o superior y no tiene otras dependencias. Necesitás además al menos uno de los CLIs oficiales instalado y logueado (claude, codex o agy): el router no los instala por vos.

  • macOS: Homebrew o pipx.
  • Linux: pipx, con el gestor de paquetes de tu distribución.
  • Windows: instalás WSL 2 una vez y seguís los pasos de Linux dentro de Ubuntu.
  1. 1 · Instalá

    macOS

    Homebrew$ brew install Mgobeaalcoba/tap/ia-router

    O con pipx: brew install pipx && pipx ensurepath y luego pipx install ia-router.

    Linux

    Debian / Ubuntu$ sudo apt update && sudo apt install -y pipx curl && pipx ensurepath
    Fedora$ sudo dnf install -y pipx curl && pipx ensurepath
    pipx$ pipx install ia-router

    En otra distribución: python3 -m pip install --user pipx && python3 -m pipx ensurepath. Abrí una terminal nueva después de ensurepath.

    Windows (WSL 2)

    PowerShell (admin)$ wsl --install -d Ubuntu

    Reiniciá, abrí Ubuntu desde el menú Inicio, creá tu usuario y seguí los pasos de Linux de arriba dentro de esa ventana. Instalá y logueá claude, codex o agy también dentro de WSL. Para la interfaz web usá ia-router ui --no-open y abrí la dirección que imprime en tu navegador de Windows.

  2. 2 · Verificá
    $ ia-router --version
    $ ia-router doctor

    doctor muestra qué CLIs tenés instalados y qué modelo usa cada uno, sin gastar cuota. Si dice command not found, ejecutá pipx ensurepath y abrí una terminal nueva.

  3. 3 · Abrilo
    $ ia-router

    La primera vez revisa qué CLIs tenés instalados y te da el paso exacto para los que falten; después, antes de gastar algo, detecta qué modelo usa cada uno y, si las métricas son viejas, ofrece actualizarlas.

  4. 4 · (Opcional) Sumá velocidad y costo

    Creá una clave gratuita en artificialanalysis.ai y guardala en un archivo .env:

    $ mkdir -p ~/.ia-router && echo 'ARTIFICIAL_ANALYSIS_API_KEY=tu_clave' > ~/.ia-router/.env
    $ ia-router metrics refresh
  5. Actualizar y desinstalar

    Homebrew: brew upgrade ia-router · brew uninstall ia-router
    pipx: pipx upgrade ia-router · pipx uninstall ia-router
    pip: python3 -m pip install -U ia-router · python3 -m pip uninstall ia-router

    Desinstalar no borra tus datos (~/.ia-router).

Nuevo en 0.6

Para scripts, para comparar y para cuidar tu cuota.

Nuevo · en el navegador

La misma herramienta, también sin terminal.

ia-router ui abre una pestaña local con la misma identidad que el CLI. Una regla: lo que se puede hacer en uno se puede hacer en el otro. Escucha solo en 127.0.0.1 y cada pedido necesita un token aleatorio.

Con honestidad

Lo que conviene saber.

  • Arena mide preferencia humana, no si la respuesta es correcta. Por eso se complementa con benchmarks con respuesta correcta cuando hay clave.
  • Con modelos de frontera, la precisión suele empatar dentro del margen de error. Ahí desempatan la velocidad y el costo.
  • El costo es el precio de lista por token: un proxy del consumo de cuota, no tu cuota real de suscripción.
  • Mide modelos, no tu CLI. Cada CLI puede correr con otro nivel de esfuerzo que el del ranking; se marca como aproximado.
Preguntas

Lo que suelen preguntar.

¿Cuesta algo?

No. ia-router es software gratuito y de código abierto (Apache-2.0). Usás tus propias suscripciones de Claude, Codex y Antigravity; el router no agrega ningún costo.

¿Mis prompts pasan por algún servidor tuyo?

No. Cada tarea se ejecuta en el CLI oficial que ya tenés logueado. El router solo lee páginas públicas de Arena y, si activás la clave gratuita, consulta la API de Artificial Analysis. El log de uso no guarda tus prompts; las conversaciones guardadas para retomarlas sí, pero solo en tu máquina, con permisos solo para vos, y podés apagarlas o borrarlas.

¿En qué sistemas operativos funciona?

En macOS y Linux, y en Windows a través de WSL 2 (el Linux que trae Windows). En Windows se instala una vez WSL con wsl --install -d Ubuntu y, dentro de Ubuntu, se siguen los pasos de Linux; los CLIs oficiales (claude, codex, agy) también se instalan dentro de WSL. Abajo están los pasos de cada sistema.

¿Lo instalo con Homebrew o con pip?

Si usás macOS con Homebrew, brew install Mgobeaalcoba/tap/ia-router es lo más simple. En Linux y en Windows (WSL), pipx install ia-router. Los dos instalan el mismo programa y se actualizan y desinstalan de forma independiente.

¿Qué modelos soporta?

Los tres CLIs oficiales: claude (Claude Code), codex (OpenAI Codex) y agy (Antigravity, de Google). Alcanza con tener uno instalado, aunque reparte mejor con varios. Se pueden agregar otros editando un archivo de configuración.

¿Qué tan confiables son las métricas?

La precisión sale de Arena (preferencia humana en comparaciones a ciegas, con control de estilo y margen de error) y, con clave, de benchmarks con respuesta correcta de Artificial Analysis. Las diferencias que caen dentro del margen de error no premian a nadie, y cada puntaje muestra sus fuentes.

¿Cómo se mantienen al día?

El software trae incluida la última foto de Arena, así que funciona sin red. Al iniciar, si las métricas tienen más de 7 días, te ofrece actualizarlas y te muestra cada paso y qué cambió en el ruteo. Nada se consulta sin que lo pidas.

¿Qué pasa si no tengo instalados los tres CLIs?

Funciona con uno solo, aunque todo irá a ese modelo. La primera vez que abrís el chat, si falta algún CLI o no iniciaste sesión, te muestra una tabla y el paso exacto para cada uno (instalar e iniciar sesión). Podés repetirlo cuando quieras con /setup o con ia-router setup, y opcionalmente verificar las sesiones (una consulta mínima por CLI, siempre preguntando antes). El router no instala nada ni inicia sesión por vos.

¿Hay una interfaz gráfica o solo terminal?

Las dos. Con ia-router ui se abre una pestaña del navegador con la misma identidad que la terminal: chat con respuestas en vivo, adjuntos, comparar modelos, vista previa del ruteo, puntajes, prioridades, métricas, uso y un administrador de conectores. Todo lo que hace el CLI se puede hacer ahí y al revés. Corre solo en tu máquina (127.0.0.1) y cada pedido necesita un token aleatorio; no hay nada que instalar ni dependencias nuevas.

¿Qué son los conectores y es seguro darle acceso a mi mail?

Los conectores son servidores MCP (Gmail, Calendar, Slack, GitHub…) que el router le da a cualquier modelo. Cada servidor hace su propio login: el router nunca toca tus tokens. Por defecto pueden leer y escribir, así que un modelo podría enviar un mail si se lo pedís; podés ocultar herramientas con listas allow/deny o apagarlos con /connectors off. Cada llamada queda en un log local sin argumentos ni resultados.

¿Está en inglés o en español?

La interfaz y la documentación del programa están en inglés. El clasificador de tareas entiende tareas escritas en inglés y en español.

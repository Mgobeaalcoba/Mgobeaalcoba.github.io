The story in 8 steps

From a blank page to a published agent

  1. 01

    First we decide who it is

    +
    Identity

    An agent starts with a name, a role and a voice. We took the rules of the assistant we already had in n8n and moved them into the agent instructions, so they no longer depend on the browser.

    Name
    MGA Assistant
    Role
    Technical and commercial assistant of MGA Tech Consulting
    Tone
    Professional, technical, clear and friendly
    Language
    The one the person writes in
    Ask the assistant:What services does MGA offer?
  2. 02

    Then we set its limits

    +
    Rules

    A public assistant has to know what not to do. We defined the forbidden topics, a few rules that are never broken and the message it uses to decline politely.

    Forbidden topics
    Weather, politics, history, jokes, programming unrelated to the services
    Strict rules
    Never invent information · Never name the team or its size
    If it goes off-topic
    Declines with its own message and goes back to the services
    Ask the assistant:How is the weather in Buenos Aires today?
  3. 03

    We give it something to read

    +
    Knowledge

    We loaded the 29 technical blog articles, the same ones the n8n agent consulted. The platform splits them into fragments and looks up the closest ones before answering.

    Source
    29 blog articles (Markdown)
    Result
    233 fragments ready to query
    Search
    Lexical and local, no external services
    Ask the assistant:What do you recommend to reduce BigQuery costs?
  4. 04

    We give it something to do

    +
    Tools

    Income tax math cannot be made up by a model. We turned it into a tool the agent calls with the data the person gave, and that is read-only.

    MCP server
    mga (internal)
    Tool
    calcular_ganancias · read-only
    Who computes
    The tool, with the January-June 2026 brackets
    { "sueldo_bruto_mensual": 4000000,
  "hijos": 1, "conyuge": true }
→ neto_mensual_estimado: 3280178
    Ask the assistant:I earn 4,000,000 gross per month, with a child and a spouse. What is my net pay?
  5. 05

    We connect it to a real database

    +
    Data

    So it can answer with portfolio and pack data, we connected it to PostgreSQL with a read-only user. The model proposes the query and the platform validates and limits it before running it.

    Database
    PostgreSQL, read-only user
    Allowed tables
    18 of 59: portfolio, packs, blog and taxes
    Left out
    Contacts, students, payments and conversations
    Limits
    SELECT only, with time and row caps
    Ask the assistant:What consulting packs do you offer?
  6. 06

    We give it the brand look

    +
    Look

    We picked the MGA colors, a short greeting and four quick replies to get started. We placed it at the bottom left so it lives next to the current assistant.

    Colors
    Cyan #22d3ee on dark #070b12
    Position
    Bottom left
    • Calculate my income tax
    • What services do you offer?
    • I want to automate a process
    • Contact the team
    Ask the assistant:I want to automate a process
  7. 07

    We publish it with one line

    +
    Publish

    We authorized the domains where it may answer and copied a one-line script. From any other site, the agent does not answer.

    Domains
    www.mgatc.com, mgatc.com and the previews
    Widget size
    11.6 KB, isolated in Shadow DOM
    <script src="https://agents.mgatc.com/widget/agent.js"
        data-agent="<ID-DEL-AGENTE>" async></script>
    Ask the assistant:Hi, what can you do for me?
  8. 08

    We test, look and tune

    +
    Test and measure

    Every conversation leaves step-by-step traces: what the router decided, which fragments it read, which tool it called. With that we tune the agent and control spend before every model call.

    Traces
    Router, knowledge, tool and data
    Analytics
    Conversations, resolution and most asked topics
    Costs
    Credits and spend cap, with optional own key
    Contacts
    Handed to a person by email
    Ask the assistant:I want to talk to someone from the team

You saw how it was built. Now try it.

Ask it to compute your income tax, search the blog or tell you which packs we offer.
